# TalkETalk

 - [ ] Real-time messaging 
 - [ ] Typing indicator 
 - [ ] Delivery/read receipts 
 - [ ] Media upload 
 - [ ] Notifications 
 - [ ] Group chat 
 - [ ] Search messages
